## 仕様書の構成

各テーブルの仕様書には以下の情報が含まれています：

### 1. テーブル概要
- テーブル論理名
- テーブル物理名
- 用途
- 実装状況

### 2. テーブル定義
- カラムの詳細情報（論理名、物理名、データ型、桁数、NULL可否、キー情報等）

### 3. インデックス
- 主キーインデックス
- 外部キーインデックス
- 検索用インデックス

### 4. 制約
- 主キー制約
- 外部キー制約
- NOT NULL制約
- CHECK制約
- UNIQUE制約

### 5. DDL
- テーブル作成SQL
- インデックス作成SQL

### 6. サンプルデータ
- テスト・開発用のサンプルINSERT文

### 7. 使用箇所
- DAO（Data Access Object）
- BL（Business Logic）
- DTO（Data Transfer Object）
- Form
- 画面

### 8. データメンテナンス方針
- バックアップ方針
- データ保持期間
- 更新頻度

### 9. ビジネスルール
- テーブル固有のビジネスルール
- データ整合性ルール

### 10. リレーションシップ
- 親テーブルとの関係
- 子テーブルとの関係

### 11. 改善提案
- データ型の改善案
- 正規化の改善案
- パフォーマンス改善案
