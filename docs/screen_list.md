### SC-001: トップページ

#### 概要
システムの入口となるメインメニュー画面。各機能へのナビゲーションを提供。

#### 画面レイアウト
- 2×2のタイルメニュー形式
- 各タイルにアイコンと機能名を表示

#### 表示項目
- **購入申請書作成** ボタン（青色）
- **購入履歴参照** ボタン（青色）
- **物品マスタ** ボタン（黄色）
- **社員マスタ** ボタン（黄色）

#### 操作
- 各ボタンをクリックすると対応する画面に遷移

#### 遷移先
- 購入申請書作成 → SC-004
- 購入履歴参照 → SC-005
- 物品マスタ → SC-006
- 社員マスタ → SC-002

### SC-002: 社員マスタ

#### 概要
社員情報の登録、更新、削除を行う画面。

#### 画面レイアウト
- 入力フォーム形式
- 上部に操作ボタン
- 中部に入力項目
- 下部に実行ボタン

#### 表示項目

##### 操作エリア
- **一覧表示** ボタン：社員一覧画面への遷移

##### 検索エリア
- **社員 - 選択** ドロップダウン：登録済み社員の選択

##### 入力エリア
| 項目名 | 必須 | 形式 | 最大桁数 | 備考 |
|--------|------|------|---------|------|
| 社員番号 | ○ | 数値 | 4桁 | 新規登録時のみ入力可能 |
| OA番号 | ○ | 数値 | 7桁 | |
| 氏名（漢字） | ○ | 全角 | 11文字 | |
| 氏名（カナ） | ○ | 半角 | 21文字 | |
| 部署 | ○ | 選択 | - | ドロップダウン選択 |
| 所属グループ | ○ | 選択 | - | ドロップダウン選択 |

##### 実行ボタン
- **登録する** ボタン（新規登録時）
- **更新する** ボタン（更新時）
- **削除する** ボタン（更新時）

#### 操作フロー

##### 新規登録
1. 各項目に値を入力
2. 「登録する」ボタンをクリック
3. バリデーション実行
4. 成功時：成功メッセージ表示、フォームクリア
5. 失敗時：エラーメッセージ表示

##### 更新
1. 社員選択ドロップダウンから対象社員を選択
2. 社員情報が自動入力される
3. 必要な項目を修正
4. 「更新する」ボタンをクリック
5. 成功時：成功メッセージ表示
6. 失敗時：エラーメッセージ表示

##### 削除
1. 社員選択ドロップダウンから対象社員を選択
2. 「削除する」ボタンをクリック
3. 成功時：成功メッセージ表示、フォームクリア
4. 失敗時：エラーメッセージ表示

#### バリデーション
- 社員番号：必須、半角数値4桁
- OA番号：必須、半角数値7桁
- 氏名（漢字）：必須、全角11文字以内
- 氏名（カナ）：必須、半角21文字以内
- 部署：必須
- 所属グループ：必須

#### メッセージ
- **成功メッセージ**：
  - 「社員情報の登録に成功しました。」
  - 「社員情報の更新に成功しました。」
  - 「社員情報の削除に成功しました。」
- **エラーメッセージ**：
  - バリデーションエラー（各項目のエラー内容）
  - 「入力した社員番号はすでに登録されています。」
  - 「DB接続時に予期せぬエラーが発生しました。」

#### 遷移元
- SC-001（トップページ）

#### 遷移先
- SC-003（社員マスタ一覧）
