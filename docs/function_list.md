## 機能詳細

### 1. 共通機能

#### F-001: ログイン機能
- **概要**: ユーザー認証を行い、システムへのアクセスを制御する
- **実装状況**: ❌ 未実装
- **優先度**: 高
- **入力項目**:
  - ユーザーID（必須）
  - パスワード（必須）
- **処理内容**:
  1. ユーザーID、パスワードの入力
  2. 認証情報の検証
  3. セッション生成
  4. メニュー画面へ遷移
- **エラー処理**:
  - 認証失敗時：エラーメッセージ表示
  - アカウントロック機能

#### F-002: ログアウト機能
- **概要**: セッションを破棄し、ログアウトする
- **実装状況**: ❌ 未実装
- **優先度**: 高
- **処理内容**:
  1. セッション破棄
  2. ログイン画面へ遷移

#### F-003: メニュー表示機能
- **概要**: システムのメインメニューを表示する
- **実装状況**: ✅ 完成
- **優先度**: 高
- **画面ID**: SC-001
- **表示項目**:
  - 購入申請書作成ボタン
  - 購入履歴参照ボタン
  - 物品マスタボタン
  - 社員マスタボタン
- **処理内容**:
  - 各機能へのナビゲーション提供

### 2. マスタ管理機能

#### F-101: 社員情報登録
- **概要**: 新規社員情報をデータベースに登録する
- **実装状況**: ✅ 完成
- **優先度**: 高
- **画面ID**: SC-002
- **使用テーブル**: pers
- **入力項目**:
  | 項目名 | 必須 | 形式 | 備考 |
  |--------|------|------|------|
  | 社員番号 | ○ | 数値4桁 | 主キー |
  | OA番号 | ○ | 数値7桁 | |
  | 氏名（漢字） | ○ | 全角11文字以内 | |
  | 氏名（カナ） | ○ | 半角21文字以内 | |
  | 部署 | ○ | 選択 | |
  | 所属グループ | ○ | 選択 | |
- **処理内容**:
  1. 入力値のバリデーション
  2. 社員番号の重複チェック
  3. データベースへの登録
  4. 登録日時の自動設定
  5. 成功メッセージの表示
- **バリデーション**:
  - 必須チェック
  - 桁数チェック
  - 数値チェック
  - 重複チェック
- **エラー処理**:
  - バリデーションエラー時：エラーメッセージ表示
  - 重複エラー時：「入力した社員番号はすでに登録されています。」
  - DB接続エラー時：「DB接続時に予期せぬエラーが発生しました。」

#### F-102: 社員情報更新
- **概要**: 既存の社員情報を更新する
- **実装状況**: ✅ 完成
- **優先度**: 高
- **画面ID**: SC-002
- **使用テーブル**: pers
- **処理内容**:
  1. 社員選択ドロップダウンから対象社員を選択
  2. 社員情報を画面に表示
  3. 修正内容の入力
  4. バリデーション実行
  5. データベースの更新
  6. 更新日時の自動設定
  7. 成功メッセージの表示
- **制約**:
  - 社員番号は変更不可（無効化）

#### F-103: 社員情報削除
- **概要**: 既存の社員情報を削除する
- **実装状況**: ✅ 完成
- **優先度**: 高
- **画面ID**: SC-002
- **使用テーブル**: pers
- **処理内容**:
  1. 社員選択ドロップダウンから対象社員を選択
  2. 削除ボタンをクリック
  3. データベースから物理削除
  4. 成功メッセージの表示
- **注意事項**:
  - 現在は物理削除（論理削除への変更を推奨）
  - 削除確認ダイアログなし（追加推奨）

#### F-104: 社員情報検索
- **概要**: 社員選択ドロップダウンから社員を選択し、情報を表示する
- **実装状況**: ✅ 完成
- **優先度**: 高
- **画面ID**: SC-002
- **使用テーブル**: pers
- **処理内容**:
  1. ドロップダウンに全社員リストを表示
  2. 社員選択時にJavaScriptで自動送信
  3. 選択された社員情報をデータベースから取得
  4. フォームに社員情報を表示

#### F-105: 社員情報一覧表示
- **概要**: 登録されている全社員情報を一覧表示する
- **実装状況**: ✅ 完成
- **優先度**: 高
- **画面ID**: SC-003
- **使用テーブル**: pers
- **処理内容**:
  1. データベースから全社員情報を取得
  2. テーブル形式で一覧表示
- **表示項目**:
  - 社員番号
  - OA番号
  - 氏名（漢字）
  - 氏名（カナ）
  - 部署
  - 所属グループ
- **今後の拡張**:
  - ページネーション
  - ソート機能
  - 絞り込み検索

### 3. 購入申請機能

#### F-301～F-305: 購入申請書作成機能
- **概要**: 物品の購入申請書を作成する
- **実装状況**: ⚠️ 画面のみ実装
- **優先度**: 高
- **画面ID**: SC-004
- **使用テーブル**: application_header、application_detail（未実装）

**処理フロー**:
1. F-301: 申請者情報、使用目的を入力
2. F-302: 物品選択ドロップダウンから物品を選択
3. F-303: 数量を入力
4. F-304: 合計金額を自動計算
5. F-305: 申請登録処理

**実装が必要な機能**:
- 申請番号の自動採番
- 物品選択機能
- 物品の追加/削除機能
- 合計金額の自動計算
- データベースへの登録処理
- トランザクション管理

- **実装状況**: ❌ 未実装
- **優先度**: 高
- **使用テーブル**: application_header、application_detail（未実装）

**必要な画面**:

**処理フロー**:

2. F-402: 申請詳細を表示

**実装が必要な機能**:
